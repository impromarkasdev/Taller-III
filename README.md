# Taller 3 React Hooks useEffect

Aplicación de una tienda en React para el Laboratorio 3 de Programación Web. Consume `https://fakestoreapi.com/products` usando `fetch` dentro de `useEffect` y muestra nombre, descripción, imagen, precio y categoría de cada producto.

## Ejecutar en Codespaces

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Abre el puerto que indique Codespaces, normalmente `5173`.
